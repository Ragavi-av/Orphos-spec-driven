1 Dashboard Overview

! Tab 1 — Annotated Callouts
①

Orphos — Brand & Tagline

Orphos appears as the bold, prominent product name (24 px, weight 800). EXECUTIVE INTELLIGENCE PLATFORM sits immediately to the right as an uppercase tagline in muted grey — providing context without competing for attention. This appears on every page and both tabs.

②

CEO Identity · Clock · Notification Bell

The right end of the header shows the signed-in role (CEO), today's date and current time (updates every minute). A large blue person icon represents the current user. A small green bell icon overlaps the top-right of the avatar — the orange number inside the bell is the total on-track item count (tracker indicator). Hover for tooltip. Alert severity chips (critical / high) appear to the left of the separator when active.

③

Metrics Row — 4 live KPI cards

Always visible. Pulls real-time data from ArcadeDB every page load. Shows system uptime vs SLA target, IT budget burn rate vs plan, active incident count, and projects currently on RAG red. Grey chip tags are OKG ontology vertex types.

④

Tab Bar — Executive Overview / Strategy & Data

Click either tab to switch between the two views. The blue underline indicates the active tab. Metrics Row and the Orphos Header Bar remain visible on both tabs.

⑤

Executive Priority Queue

Ranked list of items requiring CEO/CTO attention, scored by the EPQ engine (priority-engine-service, Caffeine cache 30 s TTL). Score circle colour: red ≥80, amber ≥60, blue ≥40, green <40. Domain chips show cross-domain impact. Live from ArcadeDB; falls back to seed data when the API is unavailable.

⑥

Recent Decisions

CEO/CTO decision audit trail written to ArcadeDB Decision vertices by decision-log-service. Each card shows title, status (APPROVED / PENDING / REJECTED), deciding authority, date, and the rationale recorded at decision time. Live from ArcadeDB; falls back to seed data.

⑦

AI Co-pilot — Natural Language Query

Type any question or click a suggestion chip. Internally: (1) Qdrant retrieves top-3 vector chunks, (2) ArcadeDB runs a structured graph query, (3) Llama 3.2 3B on Ollama synthesises the answer locally — no data leaves the network. RAG / OKG / LLM chips show which pipeline stages activated. Typical response time: 10–60 s (CPU inference).

! Tab 2 — Annotated Callouts
⑧

OKR Confidence

Progress bars for each strategic objective's key results, expressed as a confidence percentage. Bar colour: red <50% (at risk), orange 50–69% (watch zone), green ≥70% (on track). Static data — connect to ArcadeDB KeyResult vertices for live feed.

⑨

Initiative Delivery

Horizontal progress bars for each active initiative with a RAG status badge. RED = off-track, needs CEO escalation. AMB = at risk, under monitoring. GRN = on track. Static data — connect to ArcadeDB Project/Milestone vertices for live feed.

⑩

Data Flow — Live Ontology Sources

Shows the domain-to-vertex-type mapping of all data currently flowing into the knowledge graph. Three domain colours: IT, Finance, Ops. Each dot is an OWL class being ingested via Kafka → okg-ingest-service → ArcadeDB. The 15-min OKG reasoning cycle enriches these with inferred relationships in Apache Fuseki TDB2.
